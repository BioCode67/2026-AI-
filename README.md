# 천안 균형발전 나침반 (CBC · Cheonan Balance Compass)

**2026년 천안시 AI·데이터 기반 정책 아이디어 경진대회** 출품작
· 지정과제 **③ 지역균형발전** · 응모분야 **AI 모델 개발**

> 천안시 25개 생활권의 균형발전 격차를 진단하고(Diagnose),
> 3년 후 쇠퇴를 미리 경보하며(Predict),
> 한정된 예산의 생활SOC 투자 순서를 제시한다(Prescribe).

---

## 왜 이 문제인가

천안은 서북부 신도심(불당·성성)이 급성장하는 동안 동남부 원도심이 공동화되는,
**한 도시 안의 이중격차**가 전국에서 가장 뚜렷한 도시다.
그런데 현행 도시재생·생활SOC 사업지 선정은 대체로 **정성 평가와 사후 대응**에 의존한다.
이 프로젝트는 그 의사결정을 **재현 가능한 데이터·AI 파이프라인**으로 바꾼다.

## 3-엔진 구조

| 엔진 | 하는 일 | 방법 | 산출물 |
|---|---|---|---|
| **① 진단** | 지금 얼마나 벌어져 있나 | 엔트로피 가중 CBI + K-means 유형화 | 생활권 CBI·쇠퇴단계 |
| **② 예측** | 다음에 어디가 무너지나 | LightGBM + Leave-One-Zone-Out CV + SHAP | 3년 후 쇠퇴위험도·요인분해 |
| **③ 처방** | 예산을 어디부터 쓰나 | MCLP 탐욕 최적화(형평성 제약) | 투자 우선순위 N개소 |

## 빠른 시작

```bash
pip install -r requirements.txt
python3 src/run_all.py
```

`data/raw/` 가 비어 있어도 **예시(illustrative) 데이터로 전체 파이프라인이 즉시 실행**되며,
실제 공공데이터 CSV를 넣으면 해당 지표가 자동으로 실데이터로 대체된다.
실행 로그와 산출물에 **`[REAL]` / `[ILLUSTRATIVE]`** 상태가 항상 표시되므로
예시 데이터를 실데이터로 오인해 제출할 위험이 구조적으로 차단된다.

➡ 데이터 받는 법: **[`docs/01_데이터_수집_가이드.md`](docs/01_데이터_수집_가이드.md)**

## 구조

```
src/
  config.py     25개 생활권 공간단위 설계 · 12개 지표 정의
  ingest.py     CSV 적재(인코딩 자동판별) · 주소→생활권 매칭 · 출처 추적
  features.py   지표 조립 · 중력모형 기반 생활SOC 접근성
  cbi.py        엔트로피 가중 균형발전지수 · 군집 유형화
  forecast.py   쇠퇴 조기경보 모델 · SHAP 요인분해
  optimize.py   MCLP 생활SOC 입지 최적화
  viz.py        제출용 그림 8종
  dashboard.py  단일 HTML 대시보드
  make_deck.py  기획서 PPTX 자동 생성
  run_all.py    전체 실행 진입점
outputs/figures  그림 8종      outputs/tables  분석표 9종
deliverables/    dashboard.html · 기획서.pptx
```

## 데이터 윤리

- 정식 공공데이터 포털에서 내려받은 파일만 사용 (크롤링·상업용 민간데이터 미사용)
- 전 지표가 **생활권 단위 집계값** — 개인식별정보를 다루지 않음
- 모든 출처·수집시점·컬럼을 `outputs/tables/00_데이터_출처.csv` 에 자동 기록
