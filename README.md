# 천안 균형발전 나침반 (CBC · Cheonan Balance Compass)

**2026년 천안시 AI·데이터 기반 정책 아이디어 경진대회** 출품작 · 팀 **다시봄**
· 지정과제 **③ 지역균형발전** · 응모분야 **AI 모델 개발**

> 천안시 25개 생활권의 생활여건 차이를 공공데이터로 살펴보고(Diagnose),
> 앞으로 살펴보면 좋을 곳을 미리 짚어보며(Predict),
> 생활SOC를 어디부터 놓으면 좋을지 순서를 제안드립니다(Prescribe).

---

## 왜 이 주제를 골랐나

천안은 서북부 신도심(불당·성성)이 커지는 동안 동남부 원도심과 농촌면이 반대 방향으로 움직여,
**한 도시 안에 생활여건의 차이**가 비교적 뚜렷하게 나타나는 곳입니다.
어려움의 조짐은 눈에 잘 띄지 않아서, 통계가 뚜렷해졌을 땐 이미 많이 진행된 뒤인 경우가 많습니다.
미리 알아차릴 신호가 하나쯤 더 있으면 좋겠다는 생각에서 이 작업을 시작했습니다.

현장을 아시는 분들의 경험을 대신하려는 것이 아니라, **한 번 더 확인해 보실 수 있는 참고자료**를
만들어 보고자 했습니다. 부족한 부분은 현장의 판단으로 채워주시길 바랍니다.

## 3-엔진 구조

| 엔진 | 하는 일 | 방법 | 산출물 |
|---|---|---|---|
| **① 살펴보기** | 지금 어느 정도 차이가 있나 | 엔트로피 가중 CBI + K-means 유형화 | 생활권 CBI·쇠퇴단계 |
| **② 미리 보기** | 앞으로 살펴보면 좋을 곳은 어디인가 | LightGBM + Leave-One-Zone-Out CV + SHAP | 3년 후 쇠퇴위험도·요인분해 |
| **③ 순서 정하기** | 한 곳을 놓는다면 어디부터인가 | MCLP 탐욕 최적화(형평성 제약) | 투자 우선순위 N개소 |

## 빠른 시작

```bash
pip install -r requirements.txt
python3 src/run_all.py
```

`data/raw/` 가 비어 있어도 **예시(illustrative) 데이터로 전체 파이프라인이 즉시 실행**되며,
실제 공공데이터 CSV를 넣으면 해당 지표가 자동으로 실데이터로 대체된다.
실행 로그와 산출물에 **`[REAL]` / `[ILLUSTRATIVE]`** 상태가 항상 표시되므로
예시 데이터를 실데이터로 오인해 제출할 위험이 구조적으로 차단된다.

➡ 데이터 받는 법: **[`docs/01_데이터_수집_가이드.md`](docs/01_데이터_수집_가이드.md)**

## 구조

```
src/
  config.py     25개 생활권 공간단위 설계 · 12개 지표 정의
  ingest.py     CSV 적재(인코딩 자동판별) · 주소→생활권 매칭 · 출처 추적
  features.py   지표 조립 · 중력모형 기반 생활SOC 접근성
  cbi.py        엔트로피 가중 균형발전지수 · 군집 유형화
  forecast.py   쇠퇴 조기경보 모델 · SHAP 요인분해
  optimize.py   MCLP 생활SOC 입지 최적화
  viz.py        제출용 그림 8종
  dashboard.py  단일 HTML 대시보드
  make_deck.py  기획서 PPTX 자동 생성
  run_all.py    전체 실행 진입점
outputs/figures  그림 8종      outputs/tables  분석표 9종
deliverables/    dashboard.html · 기획서.pptx · 기획서.pdf
```

## 데이터 윤리

- 정식 공공데이터 포털에서 내려받은 파일만 사용 (크롤링·상업용 민간데이터 미사용)
- 전 지표가 **생활권 단위 집계값** — 개인식별정보를 다루지 않음
- 모든 출처·수집시점·컬럼을 `outputs/tables/00_데이터_출처.csv` 에 자동 기록

## 제출물 만들기

```bash
python3 src/run_all.py          # 그림·표·대시보드·기획서(PPTX)·PDF 를 한 번에 생성
bash tools/make_pdf.sh          # PDF 만 다시 만들 때
```

PDF 변환에는 LibreOffice Impress 가 필요하다.
맑은 고딕이 없는 환경에서는 `tools/fonts.conf` 를 `~/.config/fontconfig/fonts.conf` 로
복사해 나눔고딕으로 치환해야 한글이 깨지지 않는다.
