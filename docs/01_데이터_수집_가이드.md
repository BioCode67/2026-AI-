### 1. ★★★ 행정안전부 주민등록 인구통계 (읍면동별 연령별)
- **포털**: https://jumin.mois.go.kr/
- **경로**: 상단 `주민등록 인구 및 세대현황` → `연령별 인구현황`
- **설정**: 행정구역 `충청남도 천안시` 전체 선택 / 등록구분 `전체` / 구분 `읍면동` / 연령구분단위 `10세` / 조회기간 **2016년 12월 ~ 2025년 12월 (연도별)**
- **저장**: `csv 다운로드` → 파일명을 **`data/raw/pop_jumin.csv`** 로 변경
- **왜 필요**: 읍면동별 인구·고령화율·청년비율·인구증감률 = 균형발전지수의 뼈대
- **로그인**: 불필요 ✅

### 2. ★★★ 지방행정 인허가 데이터 (업종별 인허가 — 대회 예시 데이터 명시 항목)
- **포털**: https://www.localdata.go.kr/
- **경로**: `데이터받기` → `지역별 데이터 다운로드` → 시도 `충청남도` → 시군구 `천안시`
  - (또는 `업종별 데이터 다운로드`에서 **일반음식점 / 휴게음식점 / 미용업 / 세탁업 / 학원 / 편의점** 등 생활밀착 업종 선택)
- **저장**: 압축 해제 후 CSV → **`data/raw/localdata_license.csv`** (여러 개면 `localdata_license_1.csv`, `_2.csv` … 로 두면 자동 병합됩니다)
- **핵심 컬럼**: `인허가일자`, `폐업일자`, `영업상태명`, `소재지전체주소`, `도로명전체주소`, `업태구분명`, `좌표정보(X)`, `좌표정보(Y)`
- **왜 필요**: **개업일·폐업일이 전부 있어서** 읍면동별 상권 **생존곡선·순증감 시계열**을 만들 수 있습니다. 이게 이번 제안의 핵심 무기입니다.
- **로그인**: 불필요 ✅

### 4. ★★ 생활SOC 표준데이터 (여러 개 — 받는 만큼 자동 반영)

| 검색어 | 저장 파일명 | 용도 |
|---|---|---|
| `전국 도시공원 표준데이터` | `facility_park.csv` | 공원 접근성 |
| `전국 어린이집 표준데이터` | `facility_daycare.csv` | 보육 접근성 |
| `전국 문화축제 표준데이터` / `전국 공공도서관 표준데이터` | `facility_library.csv` | 문화 접근성 |
| `전국 공공체육시설 표준데이터` | `facility_sports.csv` | 체육 접근성 |
| `건강보험심사평가원_병원정보서비스` | `facility_hospital.csv` | 의료 접근성 |
| `전국 경로당 표준데이터` | `facility_senior.csv` | 고령 복지 |

## ⚠️ 인코딩 문제가 나면
한국 공공데이터 CSV는 대부분 **CP949(EUC-KR)** 입니다. 스크립트가 `utf-8 → cp949 → euc-kr` 순으로 자동 시도하므로
**그냥 받은 그대로 넣으시면 됩니다.** 엑셀로 열어서 다시 저장하지 마세요 (컬럼이 깨집니다).
