받으신 파일은 **구글 드라이브 천안시 폴더에 그냥 올려주시면** 제가 넣겠습니다.

## 1️⃣ 상가정보 — 이미 갖고 계신 ZIP에서 뽑기 (3분)

**새로 받을 필요 없습니다.** 드라이브에 올려두신
`소상공인시장진흥공단_상가(상권)정보_20260630.zip` 안에 들어 있습니다.

1. 그 ZIP 파일과 제가 드린 `extract_cheonan_sangga.py` 를 **같은 폴더**에 둡니다
2. 그 폴더에서 터미널(또는 명령 프롬프트)을 열고:

```bash
pip install pandas
python extract_cheonan_sangga.py
```

3. 잠시 기다리면 이렇게 나옵니다:

```
열기: 소상공인시장진흥공단_상가(상권)정보_20260630.zip  (353 MB)
  [9/17] ..._충남_202506.csv   전체 87,432건 → 천안 24,180건
완료  천안_상가정보.csv   24,180건 · 3.2 MB
```

4. 생긴 **`천안_상가정보.csv`** 를 드라이브에 올려주세요

> 압축을 풀 필요 없습니다. 350MB → 3MB로 줄어듭니다.
> 파이썬이 없거나 오류가 나면 **그냥 알려주세요** — 다른 방법으로 하겠습니다.

**이걸로 채워지는 것**: 사업체 밀도 · 업종 다양성 · 생활SOC 접근성 · 인구당 시설 수

## 2️⃣ 빈집 (5분)

> KOSIS 용어가 바뀌었습니다. 이제 **"빈집" → "미거주 주택(빈집)"** 입니다.

1. https://kosis.kr 접속 → 검색창에 **`빈집`** 입력
2. 통계표 목록 **맨 위** 항목을 선택하세요:
   **`미거주주택(빈집)비율(시도/시/군/구)`**  (국가데이터처, e-지방지표, 2015~2025)
   → 비율이 이미 계산돼 있고 시계열이 길어 가장 쓰기 좋습니다
3. 지역에서 **천안시 동남구, 서북구** 체크 (아산·공주 등은 필요 없습니다)
4. 우측 상단 **[다운로드] → CSV**
5. 파일명을 **`빈집.csv`** 로 바꿔 드라이브에 올려주세요

**이걸로 채워지는 것**: 빈집률 (도시재생 후보지 선정의 핵심 지표)

> ⚠️ 이 통계는 **자치구 단위**라 동남구·서북구 두 값만 나옵니다.
> 제 코드가 각 구에 속한 생활권에 같은 값을 적용하고, 산출물에는
> **PARTIAL(구 단위 배분)** 로 표기해 가정을 드러냅니다.
> 읍면동 단위 자료가 있으면 더 좋지만, 없어도 충분히 쓸 수 있습니다.

## 3️⃣ 버스정류소 (5분)

1. https://www.data.go.kr 접속 (로그인 필요)
2. 검색창에 **`천안시 버스정류소`** 입력
3. **파일데이터** 탭에서 천안시 정류소 목록 선택 → **[다운로드]**
4. 파일명을 **`버스정류소.csv`** 로 바꿔 드라이브에 올려주세요

> 안 나오면 https://www.cheonan.go.kr → 정보공개 → 공공데이터 에서 `정류소` 검색

**이걸로 채워지는 것**: 정류장 밀도 (농촌면 이동권 지표)
