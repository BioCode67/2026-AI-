# 충남 상가정보에서 천안시만 뽑기

원본이 **68MB** 라 제가 직접 가져올 수 없습니다(10MB 제한).
천안시 행만 남기면 **3~5MB** 로 줄어듭니다.

---

## 0. 먼저 — 만든 파일이 "깨져 보인다"면

**그냥 올려주세요.** 엑셀은 UTF-8 로 저장된 CSV를 열면
멀쩡한 파일도 `ìêµ¬` 처럼 깨져 보입니다. 파일 자체는 정상일 수 있습니다.
제가 열어서 판별하겠습니다 — 진짜 깨졌으면 바로 알려드립니다.

---

## ✅ 방법 A. 엑셀 파워쿼리 (복사 안 함 · 마우스만) ← 추천

Ctrl+C 로 30만 행을 긁는 게 아니라, **엑셀이 알아서 걸러서 불러옵니다.**

1. 엑셀을 **새 빈 통합문서**로 엽니다 (원본 CSV를 직접 열지 마세요)
2. **[데이터] → [데이터 가져오기] → [파일에서] → [텍스트/CSV]**
3. 원본 CSV 선택 → 미리보기 창이 뜨면 아래쪽 **[데이터 변환]** 클릭
   *(⚠️ [로드]가 아니라 **[데이터 변환]** 입니다)*
4. 파워쿼리 편집기가 열립니다. **`시군구명`** 열의 **▼** 클릭
   → **[모두 선택]** 해제 → **`천안시`** 만 체크 → 확인
5. 좌측 상단 **[닫기 및 로드]** 클릭
6. 천안시 행만 시트에 들어옵니다 → **[파일] → [다른 이름으로 저장] → CSV UTF-8**
7. 드라이브에 올려주세요

> 3번에서 미리보기에 한글이 깨져 보이면, 미리보기 창 위쪽
> **[파일 원본]** 을 `949: 한국어` 또는 `65001: 유니코드(UTF-8)` 로 바꿔
> 안 깨지는 쪽을 고르시면 됩니다.

## 방법 B. PowerShell (인코딩 자동 판별판)

앞서 드린 것이 깨졌다면 원본이 UTF-8 이었을 가능성이 큽니다.
아래는 **인코딩을 스스로 찾아서** 같은 방식으로 저장합니다.

```powershell
$f = ".\소상공인시장진흥공단_상가(상권)정보_충남_202606.csv"
$enc = $null
foreach ($n in 'utf-8','ks_c_5601-1987') {
  $e = [Text.Encoding]::GetEncoding($n)
  $head = [IO.File]::ReadLines($f, $e) | Select-Object -First 1
  if ($head -match '시군구|상호명') { $enc = $e; break }
}
if (-not $enc) { Write-Host "인코딩 판별 실패"; return }
$lines = [IO.File]::ReadAllLines($f, $enc)
$out = @($lines[0]) + ($lines | Select-Object -Skip 1 | Where-Object { $_ -like "*천안시*" })
[IO.File]::WriteAllLines(".\천안_상가정보.csv", $out, $enc)
Write-Host "완료: $($enc.WebName) / $($out.Count - 1) 행"
```

마지막에 `완료: utf-8 / 24180 행` 처럼 찍히면 성공입니다.

## 방법 C. 그래도 안 되면 — 8등분해서 올리기

```powershell
$f = ".\소상공인시장진흥공단_상가(상권)정보_충남_202606.csv"
$e = [Text.Encoding]::UTF8
$lines = [IO.File]::ReadAllLines($f, $e)
$head = $lines[0]; $body = $lines | Select-Object -Skip 1
$size = [math]::Ceiling($body.Count / 8)
for ($i = 0; $i -lt 8; $i++) {
  $chunk = @($head) + ($body | Select-Object -Skip ($i * $size) -First $size)
  [IO.File]::WriteAllLines(".\충남_$($i+1).csv", $chunk, $e)
}
```

`충남_1.csv` ~ `충남_8.csv` 를 전부 올려주시면 제가 합쳐서 걸러내겠습니다.
**인코딩이 틀려도 상관없습니다** — 제 코드가 자동 판별합니다.
