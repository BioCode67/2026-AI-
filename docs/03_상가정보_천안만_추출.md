# 충남 상가정보에서 천안시만 뽑기 (파이썬 없이)

받으신 `소상공인시장진흥공단_상가(상권)정보_충남_202606.csv` 는 **68MB** 라
제가 직접 가져올 수 없습니다(10MB 제한). 천안시 행만 남기면 **3~5MB** 로 줄어듭니다.

아래 **둘 중 편한 방법 하나만** 하시면 됩니다.

---

## 방법 A. 엑셀 (마우스만, 설치 불필요) ← 추천

1. CSV 파일을 **엑셀로 엽니다** (68MB라 열리는 데 1~2분 걸립니다)
2. 상단 **[데이터] → [필터]** 클릭
3. **`시군구명`** 열의 **▼** 를 누릅니다
4. **[모두 선택]** 체크를 해제하고 → **`천안시`** 만 체크 → 확인
5. `Ctrl` + `A` (전체 선택) → `Ctrl` + `C` (복사)
   *필터가 걸려 있으면 화면에 보이는 행만 복사됩니다*
6. `Ctrl` + `N` (새 통합문서) → `Ctrl` + `V` (붙여넣기)
7. **[파일] → [다른 이름으로 저장]** → 형식 **CSV (쉼표로 분리)** → 파일명 `천안_상가정보.csv`
8. 구글 드라이브에 올려주세요

> 저장할 때 "일부 기능이 손실될 수 있습니다" 경고가 뜨면 **[예]** 를 누르시면 됩니다.

---

## 방법 B. PowerShell (윈도우 기본 내장, 한 줄)

1. CSV 가 있는 폴더에서 주소창에 `powershell` 이라고 치고 Enter
2. 아래를 통째로 붙여넣고 Enter (1~2분 걸립니다)

```powershell
Import-Csv ".\소상공인시장진흥공단_상가(상권)정보_충남_202606.csv" -Encoding Default |
  Where-Object { $_.시군구명 -like "*천안*" } |
  Export-Csv ".\천안_상가정보.csv" -NoTypeInformation -Encoding Default
```

3. 생긴 `천안_상가정보.csv` 를 드라이브에 올려주세요

---

|---|---|---|

| 사용 지표 | 3개 (인구 축만) | **7개 / 3개 도메인** |
| 살펴보기 엔진 | 동작 | 동작 (더 정확) |
| 미리 보기 엔진 | 동작 | 동작 (더 정확) |
| **순서 정하기 엔진** | **미동작** | **동작** (지도·우선순위표 생성) |

> 지수 이름을 정직하게 낮춰 두었습니다. 이 파일이 들어오면 원래 설계대로 복원됩니다.
