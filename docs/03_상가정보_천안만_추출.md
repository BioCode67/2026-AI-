# 충남 상가정보에서 천안시만 뽑기

받으신 `소상공인시장진흥공단_상가(상권)정보_충남_202606.csv` 는 **68MB** 라
제가 직접 가져올 수 없습니다(10MB 제한). 천안시 행만 남기면 **3~5MB** 로 줄어듭니다.

> ⚠️ **엑셀에서 필터 → Ctrl+A → Ctrl+C 는 하지 마세요.**
> 필터가 걸린 30만 행을 복사하는 작업이라 엑셀이 멈추거나 튕깁니다.
> 아래 방법을 쓰시면 몇 초 만에 끝납니다.

---

## ✅ 방법 A. PowerShell (윈도우 기본 내장 · 몇 초)

1. CSV 가 있는 **폴더를 파일 탐색기로 엽니다**
2. 주소창(파일 경로 나오는 칸)을 클릭하고 `powershell` 이라고 친 뒤 **Enter**
3. 아래 **5줄을 통째로** 복사해 붙여넣고 **Enter**

```powershell
$f = ".\소상공인시장진흥공단_상가(상권)정보_충남_202606.csv"
$e = [Text.Encoding]::GetEncoding(949)
$lines = [IO.File]::ReadAllLines($f, $e)
$out = @($lines[0]) + ($lines | Select-Object -Skip 1 | Where-Object { $_ -like "*천안시*" })
[IO.File]::WriteAllLines(".\천안_상가정보.csv", $out, $e)
```

4. 같은 폴더에 **`천안_상가정보.csv`** 가 생깁니다 → 드라이브에 올려주세요

> 파일명이 다르면 1번째 줄의 이름만 실제 파일명으로 바꿔주세요.
> 붙여넣기는 PowerShell 창에서 **마우스 오른쪽 클릭** 하면 됩니다.

---

## 방법 B. 엑셀로 꼭 하셔야 한다면 — 필터 말고 **정렬**

필터 후 복사가 느린 이유는 흩어진 행을 하나씩 긁어오기 때문입니다.
정렬하면 천안시 행이 **한 덩어리로 모여** 훨씬 빠릅니다.

1. **[데이터] → [정렬]** → 기준 열 **`시군구명`** → 오름차순
2. 천안시 행이 연속으로 모입니다. 왼쪽 행번호를 드래그해 **그 구간만 선택**
3. `Ctrl` + `C` → `Ctrl` + `N` (새 통합문서) → `Ctrl` + `V`
4. **첫 줄에 머리글(컬럼명)을 직접 붙여넣으세요** (원본 1행을 복사)
5. **다른 이름으로 저장 → CSV** → 드라이브 업로드

---

## 방법 C. 그냥 파일을 반으로 잘라 올리기

위 두 방법이 다 안 되면, PowerShell 로 파일을 8등분해서 올려주셔도 됩니다.

```powershell
$f = ".\소상공인시장진흥공단_상가(상권)정보_충남_202606.csv"
$e = [Text.Encoding]::GetEncoding(949)
$lines = [IO.File]::ReadAllLines($f, $e)
$head = $lines[0]; $body = $lines | Select-Object -Skip 1
$size = [math]::Ceiling($body.Count / 8)
for ($i = 0; $i -lt 8; $i++) {
  $chunk = @($head) + ($body | Select-Object -Skip ($i * $size) -First $size)
  [IO.File]::WriteAllLines(".\충남_$($i+1).csv", $chunk, $e)
}
```

→ `충남_1.csv` ~ `충남_8.csv` 가 생깁니다. 전부 올려주시면 제가 합쳐서 천안만 걸러내겠습니다.
